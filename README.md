# 🎮 GamerFan

**GamerFan** — это социальная сеть для геймеров, объединяющая общение, контент и игры в одном пространстве. Платформа создана для тех, кто хочет делиться новостями, находить друзей по интересам и играть прямо в браузере.

## 🌟 О проекте

GamerFan — это авторский проект, разработанный с нуля для комфортного времяпрепровождения игрового сообщества. Сайт сочетает в себе функции классической социальной сети и игровой платформы, позволяя пользователям не только общаться, но и сразу запускать любимые игры.

## 🚀 Ключевые возможности

*   **Лента активности** — публикация постов с фотографиями, система лайков и древовидные комментарии.
*   **Мессенджер** — личные чаты в реальном времени с поддержкой обмена текстом и изображениями.
*   **Игровая библиотека** — встроенный оверлей для запуска игр (ELBERR OS, Slime Farm и другие) без перехода на сторонние ресурсы.
*   **Ивенты** — создание игровых событий с возможностью прикрепления собственных игр (через ZIP-архив или ссылку на GitHub).
*   **Профили** — детальная настройка аккаунта (аватар, имя, фамилия, контакты), система добавления в друзья и просмотр чужих профилей.
*   **Персонализация** — четыре темы оформления на выбор (Киберпанк, Тёмная, Чёрная, Светлая).
*   **Модерация** — панель администратора для управления пользователями, постами и ивентами.

## 🛠 Техническая база

Проект реализован на современных веб-технологиях:
*   **Frontend**: HTML5, CSS3, JavaScript (ES6+).
*   **Backend & База данных**: Supabase (авторизация, PostgreSQL, файловое хранилище, работа в реальном времени).
*   **Хранение медиа**: ImgBB API (для изображений) и Supabase Storage (для игровых файлов).
*   **Обработка архивов**: JSZip.
